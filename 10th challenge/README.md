ALGORITHM
1. Start.
2. Declare arrays to store temperature, humidity and AQI for 5 zones and 7 days.
3. Display the main menu.
4. Read the user's choice.
5. If choice is 1, enter or update environmental readings.
6. If choice is 2, display all readings in matrix form.
7. If choice is 3, calculate and display the average temperature, humidity and AQI for each zone.
8. If choice is 4, identify risk days based on temperature, humidity and AQI.
9. If choice is 5, calculate the Green Index and rank all five zones.
10. If choice is 6, display recommendations for each zone.
11. If choice is 7, exit the program.
12. Repeat the menu until the user selects Exit.
13. Stop.
