ALGORITHM
1. Start.
2. Read the number of tickets N (5 to 15).
3. Enter N ticket IDs and check their range.
4. Display the original sequence.
5. Find the duplicated and missing ticket IDs.
6. If the scan log is invalid, display an error and stop.
7. Count the out-of-order pairs.
8. Read the last two digits of the registration number.
9. Calculate the target ticket using `(R % N) + 1`.
10. Display the target ticket, its positions, and occurrence count.
11. Stop.
