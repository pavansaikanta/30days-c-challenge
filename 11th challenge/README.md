ALGORITHM
1. Start.
2. Read water usage and daily targets for all 5 zones.
3. Validate the entered values.
4. Display the water usage details.
5. Show the menu.
6. Calculate totals, averages, peaks and water alerts.
7. Rank the zones based on excess water.
8. Display conservation suggestions.
9. Repeat the menu until Exit is selected.
10. Stop.
