Algorithm
1. START the program.
2. Initialize all expense counts and totals to zero.
3. Read the expense amount from the user.
4. If the expense amount is 0, go to Step 8 (STOP).
5. If the expense amount is negative, display "Invalid expense!" and go back to Step 3.
6. If the expense amount is positive:
   - If the amount is below 100, classify it as Small.
   - If the amount is 100 or above but below 500, classify it as Medium.
   - If the amount is 500 or above, classify it as Large.
   Update the corresponding count and total.
7. Repeat Steps 3–6 until the user enters 0. Then calculate and display the total valid expenses, category-wise counts and totals, and average. If there are no valid expenses, display "No valid expenses entered."
8. STOP the program.
